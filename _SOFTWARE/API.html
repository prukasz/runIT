runIT — API: opcode'y routerów i urządzeń

Wygenerowane z runit-app/generated/ (contract_*.json, device_*.json); opy tylko lokalne nie są komendami i ich tu nie ma. Odświeżenie: python tools/gen_api_html.py. Routery: 62 operacji · kontrakty: 38 · operacje własne urządzeń: 27.

Format ramek

CelRamka (po nagłówku sesji, little-endian, packed)
Router modułu[router_key u8][dir u8][op u8][args…]
Urządzenie[0x2F][dir u8][id u8][op u16][args…] — op = (contract << 8) | n, własne urządzenia: 0xFFnn
dirR CMD_DIR_READ = 0 — pyta o wartość · W CMD_DIR_WRITE = 1 — ustawia / wykonuje akcję
Zdarzenia[0x06][sys_event_t] (PUSH na strumieniu EVENT_STREAM_NOTIFY = 0x06); tag = (module << 16) | n (0x8000 | type_id dla własnych urządzeń)

Klucze routerów = numery modułów MODULE_ID_* (module_id.h). Kontrakt DEVICE ma 0x2F (op 0x07 zarezerwowany).
