runIT — API: opcode'y routerów i urządzeń

Wygenerowane z runit-app/generated/ (contract_*.json, device_*.json); opy tylko lokalne (np. DISPLAY FLUSH) nie są komendami i ich tu nie ma. Odświeżenie: python tools/gen_api_html.py. Routery: 118 operacji · kontrakty: 32 · operacje własne urządzeń: 18.

Format ramek

CelRamka (po nagłówku sesji, little-endian, packed)
Router modułu[router_key u8][dir u8][op u8][args…]
Urządzenie[0x05][dir u8][device id u16][op u16][args…] — op = (contract << 8) | n, własne urządzenia: 0xFFnn
dirR CMD_DIR_READ = 0 — pyta o wartość · W CMD_DIR_WRITE = 1 — ustawia / wykonuje akcję
Zdarzenia[0x07][NOTIFY 0x01][sys_event_t] na strumieniu events (bez komend); event ID = (contract << 8) | n

Klucze wolne: 0x09 (nigdy nie przydzielać). Log: op 0x02 nieużywany.

Puts the board in its safe state: switches off the device outputs and stops the VM.
—bez argumentów
0x03RESTART

Restarts the ESP32 after the answer is sent (about 100 ms later).

0x04DEADMAN

Sets the dead-man: the timeout of the clients' sessions, whose end (silence that long, the link lost) enters the safe state. 0 = off: the board then runs its program on its own, with no client. Runtime only: after a restart the board is as built (off by default).

→ sys_system_deadman_t timeout_ms:u32
Dead-man settings
arg: sys_system_deadman_t timeout_ms:u32
0x06BYE
SYS_SYSTEM_OP_BYE
WSay goodbye
The app leaves on purpose (its Disconnect, its window closing): the board turns the dead-man off and goes on with what it runs. Without it a dead-man the app armed would stop the board after the silence that follows. A link that drops without it (power, range) is a lost link as before.
—bez argumentów

Gives the board the time (UTC, milliseconds since 1970). The board has no battery clock: the app sets it whenever it connects, and it is lost at a restart.
arg: sys_system_time_t unix_ms:u64

RSafe state
Whether the board is in its safe state (the VM stopped, every device output off and suspended), why it entered it and how long ago. A reason of 0: not in it.

—bez argumentów
