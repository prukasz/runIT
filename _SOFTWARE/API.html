runIT — API: opcode'y routerów i urządzeń

Wygenerowane z runit-app/generated/ (contract_*.json, device_*.json); opy tylko lokalne nie są komendami i ich tu nie ma. Odświeżenie: python tools/gen_api_html.py. Routery: 63 operacji · kontrakty: 38 · operacje własne urządzeń: 9.

Format ramek

CelRamka (po nagłówku sesji, little-endian, packed)
Router modułu[router_key u8][dir u8][op u8][args…]
Urządzenie[0x20][dir u8][id u8][op u16][args…] — op = (contract << 8) | n, własne urządzenia: 0xFFnn
dirR CMD_DIR_READ = 0 — pyta o wartość · W CMD_DIR_WRITE = 1 — ustawia / wykonuje akcję
Zdarzenia[0x06][sys_event_t] (PUSH na strumieniu RUNIT_STREAM_EVENTS = 0x06); tag = (module << 16) | n (0x8000 | type_id dla własnych urządzeń)

Klucze routerów = numery modułów MODULE_ID_* (module_id.h). Kontrakt DEVICE ma 0x20 (op 0x07 zarezerwowany).

It speeds up and slows down along ramps, never in one jump, goes through stop when it changes direction, ignores a dead zone round stop, starts at the speed where it turns, keeps under a top speed and can be trimmed and reversed. It can stop itself when it stalls.
