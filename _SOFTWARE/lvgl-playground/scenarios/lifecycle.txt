# The adapter's lifecycle against its devices (README.md "Scenarios"): the display and the touch held from INSTALL to
# RESET (REMOVE refused, ERR_DEV_HELD), a RESET of the display from the app while a transfer is in flight (the FLUSH
# ends there: no FLUSH_TIMEOUT), ROTATION while the display is suspended (the panel turns when it resumes).
# Frames: [key][dir 00 read / 01 write][...], little-endian. DEVICE (05): [dir][id u16][op u16][args].
# LVGL (15): [dir][op][args]. Device ids here: the display 1, the touch 2, the GPIO 3.
