# TPS55289

The regulator's own protection settings.

Voltage, current limit and enable are the Regulator block. This one is how the chip protects itself; usually it is set once with the device, the block is for a program that changes it while it runs.

## Settings

| Setting | Meaning |
|---|---|
| Device | The device this block works on. |
| Operation | What the block does with the device; it decides the inputs and outputs below. |
| When not enabled | An operation sent once when the enable turns off (none: the device is left as it is). Only a setting or an action can be sent. |

## Operations

### Protection

Sets how the chip protects itself.

| Pin | Meaning |
|---|---|
| OCP delay (input) | 128 us, 3.072 ms, 6.144 ms, 12.288 ms. Unwired: the value set in the block's settings. |
| Hiccup (input) | Off, On. Unwired: the value set in the block's settings. |
| Fault mask (input) | 0 to 7. Unwired: the value set in the block's settings. |
| Discharge (input) | Off, On. Unwired: the value set in the block's settings. |

### Read protection

Reads the protection settings.

| Pin | Meaning |
|---|---|
| OCP delay (output) | 128 us, 3.072 ms, 6.144 ms, 12.288 ms. |
| Hiccup (output) | Off, On. |
| Fault mask (output) | a number. |
| Discharge (output) | Off, On. |

## Behaviour

- A **setting** is sent on the first enabled pass and whenever one of its values changes; an **action** once on each rising edge of the enable; a **reading** on every enabled pass (gate it with Every to read less often) and written to the outputs.
- ENO is on while the device accepts the calls (a setting or a reading), or pulses on the pass an action was sent. A failed call is reported and ENO goes off.
- The device checks the values and refuses what it cannot do; nothing is clamped.
